# 関節可動域と破綻判定のしきい値

数値はすべて **ワールド関節位置から実測した角度**に対する目安。ポーズJSONのオイラー値を
そのまま当てはめてはいけない（測り方は `SKILL.md` 参照）。

出典は臨床で使われる関節可動域（ROM）の代表値。個人差が大きく、運動選手や柔軟性の高い人は
上限を超える。**超えている＝即エラーではなく、「意図されたポーズか確認する」合図**として使う。

## 内角と屈曲角

```
屈曲角 = 180° - 内角
```

膝を例にすると、内角180°=直立、内角37°=屈曲143°の深いしゃがみ。

## 破綻の判定順

1. **符号の異常** — 膝・肘が逆方向に曲がっていないか（内角>190°、または屈曲方向が前後逆）
2. **ねじれ** — 伸展位の膝・肘にねじれが入っていないか
3. **左右取り違え** — `_L` と `_R` が入れ替わっていないか
4. **可動域超過** — 上表を大きく超える関節が無いか
5. **貫通** — 深屈曲の膝（内角45°未満）、脇、股関節。数値で測る
6. **接地** — FootIK 後に足裏が床に乗っているか、支持脚と重心が矛盾していないか
