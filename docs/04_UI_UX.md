# 04 UI UX

## Goal

開いて10秒以内にクロッキーを始められるUI。

## Layout

```txt
Header
Viewer Area
Control Panel
```

Ver.1は1画面構成。

## Header

高さ48〜56px。アプリ名と設定ボタンのみ。

## Viewer

画面の主役。タイマーをオーバーレイ表示。

## Control Panel

- 前ポーズ
- 次ポーズ
- ランダム
- タイマー
- タグ検索
- お気に入り
- カメラリセット

## Rules

- ボタンは分かりやすく
- 演出は最小限
- 設定変更は即時反映
- 確認ダイアログは極力使わない
