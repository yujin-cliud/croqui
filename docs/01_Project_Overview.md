# 01 Project Overview

Croquiは、イラストを描く人が描き始めるまでの手間を減らし、毎日のクロッキーを続けやすくするWebアプリです。

## Concept

> 描く題材を探す時間を減らし、描く時間を増やす。

## MVP Goal

Ver.1は完成形ではなく、公開できるMVPを作る。

優先事項：

1. 安定して動作する
2. 迷わず操作できる
3. オフラインでも主要機能が使える
4. アカウントなしで使える

## MVP Decision

| 評価 | 意味 |
|---|---|
| 🟢 MVP必須 | Ver.1公開に必要 |
| 🟡 あれば良い | 余裕があれば |
| 🔵 Future | Ver.2以降 |
| ❌ 不採用 | コンセプトに合わない |

## Success Criteria

- すぐクロッキーを始められる
- ポーズ切替がスムーズ
- タイマー練習ができる
- お気に入りと設定が保存される
- オフラインで使える
